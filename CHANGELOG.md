# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-11

Каркас дополнен правилами, которые до этого дублировались в Rephlexia Studio:
меню тулбара и справка из вкладов областей, загрузчик каталога областей по
протоколу хоста, проверки этих вкладов при регистрации паспорта.

### Добавлено

- **`topbar/`** (подпуть `/topbar`) — `validateTopbarMenus`,
  `validateTopbarSections`, `collectTopbarMenus`, `toMenuSpec`, `topbarActions`,
  `helpMenuSpec`. Меню собирается только из вкладов областей: категория,
  отмеченная несколькими областями, становится общим меню с разделами под
  заголовками; раздел без категории — личным меню области.
- **`help/`** (подпуть `/help`) — `validateHelp`, `collectHelpTopics`,
  `mountHelp`. Темы справки приносят области; диалог строит вкладки и
  показывает содержимое активной, статичных страниц в каркасе нет.
- **`runtime/`** (подпуть `/runtime`) — `createScopeLoader`, `versionedModuleUrl`,
  `importScopeUrl`. Загрузчик читает каталог областей у хоста
  (`GET /api/scopes` по умолчанию), приводит области к порядку приложения,
  регистрирует паспорта, монтирует разметку, активирует реализации и собирает
  производные каталоги (инструменты, меню, справку). Повтор упавшего
  динамического импорта выполняется по свежему URL, ошибка хоста не кешируется.
- `bindScopeDependencies` — сборка зависимостей областей из метаданных и из
  разметки (`data-requires-scope`), экспортируется из `/scopes` и корня.
- `mountScopeNodes` принимает `host` и `rootHost` — списки селекторов
  контейнеров через запятую; первый найденный принимает панель. Значения по
  умолчанию (`#studioContent, main.b-main` и `#appRoot, body`) покрывают оба
  известных приложения без правок в каркасе.
- Тесты `tests/topbar.test.js` и `tests/runtime.test.js` (8 проверок): сборка
  меню и справки, порядок каталога, отсутствие кеширования ошибки, повторы
  импорта.

### Изменено

- Реестр областей проверяет вклады `topbarMenus`, `topbarSections` и `help`
  при регистрации паспорта: некорректный вклад отклоняется с сообщением об
  области, а не ломает сборку меню позже.
- Сообщения об ошибках реестра и доступности переведены на русский язык и
  называют область и поле; коды исключений не изменились.

### Изменено в зависимостях

- `uix-preparatorio` объявлен необязательной пир-зависимостью: ядро, области,
  тулбар, справка и загрузчик каталога работают без библиотеки интерфейса, а
  её версию выбирает приложение. Вложенная копия библиотеки больше не ставится.

### Совместимость

- API 1.0.0 не изменился: существующие вызовы `register`, `bind`, `get`,
  `list`, `mountScopeNodes`, `createScopeAvailability` работают как раньше.
- Проверено на Rephlexia Studio 4.0.053 (раскладка слоёв, десять областей) и
  обратно совместимо с Morphia Studio 2.0.142.

## [1.0.0] — 2026-11-11

Первый выпуск. Каркас выделен из Morphia Studio 2.0.139 в самостоятельный
пакет; логика перенесена без изменений.

### Добавлено

- **`scopes/`** — реестр паспортов областей, связывание паспорта с
  реализацией, монтирование слотов `[data-scope-slot]`, управление
  доступностью элементов управления.
- **`contributions/`** — реестры пунктов меню «Вид» и «меню области», события
  `ui:view-contributions-changed` и `ui:viewport-contributions-changed`.
- **`composition/`** — правила сборки: порядок движков (`sortEngines`) и
  областей (`createScopeOrder`), регистрация паспортов
  (`registerScopeDefinitions`), отбор областей по `requiresEngines`
  (`availablePluginScopes`), раскладка вкладов (`registerContributions`),
  загрузка плагинов движков (`loadEnginePlugins`) и связывание реализаций
  (`bindScopeImplementations`).
- **`menu/`** — перенос узлов-вкладов в контейнер меню, готовые обёртки для
  меню «Вид» и меню области.
- **`shell/`** — обёртки над `uix-preparatorio`: сворачивание секций, высоты
  раскрытых вкладок, компактная раскладка; каталог инструментов
  (`createToolCatalogue`).
- Подпутя экспорта: `/browser`, `/scopes`, `/contributions`, `/composition`,
  `/menu`, `/shell`.
- Модульные тесты на `node:test` (21 проверка) и конфигурация CI.
- Справочник API (`docs/API.md`) и иллюстрация интерфейса
  (`docs/images/demo.png`).

### Изменено по сравнению с копией в приложении

- `createScopeRegistry().bind` сравнивает `tools` и `template` по значению, а
  не по ссылке: реализация может быть собрана расширением паспорта
  (`{ ...passport, init }`).
- `createToolCatalogue` строит каталог инструментов при вызове, а не при
  импорте модуля, поэтому учитывает области, зарегистрированные позже.

### Совместимость

- Node.js ≥ 20, ES-модули.
- `uix-preparatorio` — зависимость для подпутей `/menu`, `/shell`, `/browser`.
- Проверено на Morphia Studio 2.0.139: сборка, `check:core`, `check:content`
  и запуск интерфейса проходят без изменений в поведении.
